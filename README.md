# Bellota Soluciones Digitales

Sitio inicial estático en HTML, CSS y JavaScript, listo para publicar en GitHub Pages.

## Archivos
- `index.html`: página principal.
- `portfolio.html`: página temporal de Portfolio con mensaje “Próximamente”.
- `styles.css`: estilos, diseño adaptable para celular y escritorio.
- `script.js`: menú móvil, año automático y aviso para el enlace pendiente del turnero.

## Publicar en GitHub Pages
1. Creá un repositorio en GitHub, por ejemplo `bellota-soluciones-digitales`.
2. Subí estos cuatro archivos y este README a la raíz del repositorio.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/(root)`, y guardá.
6. Esperá a que GitHub genere la URL del sitio.

## Pendiente de completar
- Reemplazar el enlace provisional del Turnero web en `index.html`.
- Agregar el email y el perfil de Instagram en la sección de contacto.
- Confirmar el enlace de WhatsApp proporcionado antes de publicar.
- Confirmar si el nombre y el símbolo de marca quedan definitivos.
- Revisar los textos, enlaces y aspecto visual una vez publicado.
